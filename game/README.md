# LAST SPARK

Unity 프로젝트와 별도로 실행하는 2D 브라우저 게임이다. Docker Compose가 웹 화면, 기록 API, MySQL을 함께 띄운다.

## 실행

PowerShell에서 `game/` 폴더로 이동한 뒤:

```powershell
Copy-Item .env.example .env
```

`.env`의 두 비밀번호를 서로 다른 값으로 바꾸고 실행한다.

```powershell
docker compose up --build -d
```

게임은 `http://localhost:8080`에서 연다. `index.html`을 파일 탐색기에서 바로 열면 브라우저 보안 때문에 API를 쓸 수 없어 기록이 이 기기에만 저장된다. DB 연결 상태는 `http://localhost:8080/api/health`에서 확인한다. `{"status":"ok","database":"connected"}`가 나오면 연결된 것이다.

중지는 `docker compose down`이다. 이 명령은 저장 기록을 보존한다. `docker compose down -v`는 MySQL 기록까지 지우므로 초기화할 때만 사용한다.

## 플레이와 기록

처음에 실제 운용 기록과 출입 로그로 이야기를 읽는다. 시작 통로의 단말기에서 사고 기록을 확보하면 보안실로 들어갈 수 있다. 출입 카드는 보안실 안쪽 데스크에 놓여 있고, 카드를 얻어야 보안 격벽이 열린다. 보안실에서 시작 통로로 돌아와 선택 구역인 E-04 연구동에 들른 뒤에도 본 경로로 이어갈 수 있다. E-04 연구동은 세 층으로 압축했다. 1층 정비·비상전력실, 2층 격리 관찰동, 3층 중앙 배전실에 발전기가 하나씩 있다. 차단기를 올리거나 새 층에 들어서면 NEXUS가 천장 해치를 연다. 바닥 경고가 켜진 곳에서 적이 떨어지며, 근접·사격·돌진형 유닛과 고정 포탑이 통로를 지킨다. 숨을 곳은 층마다 한 곳이다. 전선 스파크는 복구한 전력에 따라 줄어든다.

연구동에 들어서면 비상 사이렌이 울리고, 진입 기록을 닫은 뒤에도 잠시 이어진다. 체력이 30% 이하로 떨어져 3페이즈에 처음 진입하면 연구원이 C-7 신경 반응 촉진제를 주사하는 기록이 나온다. 기록을 마치면 남은 다리 구동부를 이용한 3단 점프가 열린다.

전투는 공격과 회피의 간격을 두도록 조정했다. `J`를 짧게 누르면 기본 공격, 0.65초 이상 누른 뒤 놓으면 강한 차징 공격이 나가며, 차징 중에는 이동이 느려진다. 차징 중에는 페이즈별 공격 시트의 준비 자세를 유지하고 에너지가 슈트 코어로 모인다. 놓으면 같은 시트의 직선 타격 동작이 이어져 내려치기 없이 공격한다. 기본 공격은 낮은 피해를 주고, 차징 공격은 기본 피해의 2.4배를 준다. 적중 순간에는 짧은 히트스톱과 작은 화면 흔들림, 적의 밀림을 더한다. 차징 공격의 반응은 조금 강하지만 화면을 번쩍이게 하지 않는다. 체력에 따라 1단계는 느리고 단단한 중장갑형, 2단계는 균형형, 3단계는 빠르지만 피해를 더 받는 파손형으로 바뀐다. 1단계는 기존 중장갑 스프라이트를 쓰고, 2·3단계는 전신 애니메이션 시트를 교체한다. 2단계에서는 깨진 외장 사이로 사람이 드러나고, 3단계에서는 사람의 전신 실루엣과 일부 장갑 잔해가 보인다. 회복해도 파손 단계는 되돌아가지 않는다. `Shift` 대시는 어느 페이즈에서나 쓸 수 있고 5초 쿨타임이 있다. `R` 응급 패치는 출격당 두 개이며 하나당 최대 체력의 10%를 회복한다. 자연 회복과 발전기 회복은 없다.

분석실과 격리 통로의 경비 수를 늘렸고 연구동은 경비·포탑과 천장 투하 병력을 최대 다섯 기까지 함께 배치한다. 중간 보스는 2페이즈, 최종 보스는 3페이즈를 유지한다. 각 페이즈에서 공격 범위와 안전 지대가 달라지고, 공격을 피하면 코어가 잠시 열려 강한 반격을 노릴 수 있다.

기록은 익명 브라우저 ID를 기준으로 출격 횟수, 누적 시간, 최고 구역·페이즈, 최고 클리어 시간을 API를 거쳐 MySQL에 동기화한다. 시작 화면에 `MySQL 연결됨` 또는 `DB 미연결`이 표시된다. 서버가 연결되지 않으면 브라우저에 저장한다. 브라우저를 바꾸면 별도 기록으로 취급된다.

조작: 이동 `A/D` 또는 방향키 · 점프 `Space` · 근접 공격 `J`/마우스 길게 누르기 · 대시 `Shift` · 응급 패치 `R` · 조사/숨기/승강기 `E` · 일시정지 `Esc` · 타이틀 `Q` · 기록 `F2`.

## 확인

- 게임 흐름: `tests/gameplay-smoke.html`
- 연구동 층·은폐·적 투하·보스 표적: `tests/research-smoke.html`
- 맵·조명: `tests/world-smoke.html`
- 전투 판정: `tests/combat-smoke.html`
- 전투 규칙: `node tests/combat-rules.test.cjs`
- 페이즈 전신 스프라이트·프레임 선택: `node tests/player-appearance.test.cjs`
- 플레이어·보스 연결: `tests/gameplay-runtime.test.cjs` (Node 런타임)
- API 검증: `python -m unittest discover -s server/tests -v`

DB는 컨테이너 내부 네트워크에만 열려 있고, 웹 요청은 Nginx → API → MySQL 순서로 전달된다. 저장소에는 `.env`를 올리지 않는다. 실행 중인 Docker Desktop이 필요하다.
