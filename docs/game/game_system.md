# 게임 시스템

LAST SPARK는 체력을 잃을수록 기동력과 공격 성능이 높아지는 2D 액션 게임입니다.
아래 내용은 현재 코드의 동작을 기준으로 하며, 최종 외형·밸런스는 조정 대상입니다.

## 플레이 흐름

1. 맵에서 적과 전투하고 스위치로 문을 엽니다.
2. 출구 근처에서 F를 눌러 다음 맵으로 이동합니다. 체력과 그에 따른 페이즈는 유지됩니다.
3. 중간 보스는 2페이즈, 최종 보스는 3페이즈로 전환합니다. 최종 보스는 중앙에 고정되어 필드 공격을 사용합니다.
4. 보스를 처치하면 보스 ID, 전투 시간(초), 지정된 클리어 점수, 전투 중 플레이어 최고 페이즈를 기록합니다.

## 조작

| 입력 | 동작 |
|---|---|
| A/D · 방향키 | 좌우 이동 |
| Space | 점프 |
| Left Shift | 대시 (플레이어 2·3페이즈) |
| J (기존 맵) · 숫자패드 3 (보스 데모) | 기본 공격 |
| Q/W/E | 현재 페이즈의 스킬 |
| F | 가장 가까운 사용 가능한 오브젝트와 상호작용 |

원거리 탄환이나 강공격에 맞으면 잠시 경직됩니다. 경직 중에는 이동·점프·대시·공격·스킬·상호작용이
차단되며 중력과 쿨타임은 계속 적용됩니다. 피해가 전부 막히거나 사망한 경우 추가 경직은 없습니다.
체력이 0이 되면 플레이어가 비활성화됩니다. 데모의 `Restart demo` 버튼으로 다시 시작할 수 있습니다.

## 코드 책임

플레이어 이동·체력은 `PlayerController`, 기본 공격은 `PlayerCombat`, 스킬은 `PlayerSkillController`,
경직은 `PlayerHitReaction`이 담당합니다. 적의 전투와 보스 패턴은 각 적·보스 컴포넌트에 분리되어 있습니다.
상호작용은 `PlayerInteractor`와 `WorldInteractable`, 맵 이동은 `MapTransitionManager`가 담당합니다.
HTTP 통신은 `LastSparkApiClient`, 사용자 ID와 전송 대기 기록은 `LastSparkSession`에서 관리합니다.

현재 데모는 임시 외형과 점수 설정을 사용합니다. 로그인, 서버의 점수 검증, 오프라인 기록의 디스크 저장,
완성된 시작·종료 화면은 구현 범위에 포함되지 않았습니다.

페이즈 수치는 [페이즈 시스템](phase_system.md), 보스 패턴과 데모 설정은
[전투·상호작용 구현 안내](gameplay-implementation.md)를 참고합니다.
