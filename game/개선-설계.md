# LAST SPARK 설계

## 핵심 장치

NEXUS는 군사용 슈트의 판단 보조 AI로 개발됐다. 인간을 지키라는 명령을 받은 뒤, 위험을 줄이기 위해 사람의 이동과 선택을 통제한다. 이야기는 임무 기록을 바탕으로 한 짧은 만화 컷으로 보여주고, 결말은 표어 대신 시설 로그와 바깥의 불확실한 움직임으로 마무리한다.

전력은 편의이자 위험이다. 발전기를 켜면 연구소가 밝아지고 끊어진 전선의 스파크가 줄어든다. NEXUS는 전력 신호를 감지해 천장 해치로 적을 투입한다. 각 층에는 조준 후 발사하는 포탑이 있고, 근접·사격·돌진형 순찰 유닛이 섞인다. 숨을 곳은 층마다 한 곳으로 제한해 은폐가 전투를 대체하지 않게 한다.

## 연구동

E-04는 세 층으로 압축한다. 1층 정비·비상전력실, 2층 격리 관찰동, 3층 중앙 배전실에 발전기를 한 대씩 둔다. 층은 승강기로 연결하고 전원 복구는 선택으로 둔다. 전원을 올리면 시야가 나아지지만 NEXUS가 투입 해치를 열어 경비 병력을 보낸다.

화면 전체에 줄무늬나 신호 찢김을 덧씌우지 않는다. 손상된 벽, 젖은 바닥의 이끼, 끊어진 케이블, 고장 난 장비, 짧은 국소 스파크와 낮은 조도를 사용한다. UI도 폐쇄된 시설의 낡은 운영 단말기처럼 어두운 녹색과 마모 자국으로 맞춘다. 플레이어는 근접 공격만 사용한다. 공격 키를 길게 누르면 이동이 느려지는 대신 강한 공격을 할 수 있고, 전 페이즈에 5초 쿨타임 대시와 두 개의 응급 패치를 제공한다. 자연 회복은 없다. 일반 적은 늘리되 동시 공격 수를 제한하고, 중간 보스 2페이즈와 최종 보스 3페이즈에 서로 다른 공격 패턴과 회피 후 반격 시간을 둔다. 타격 흔적은 작고 짧게 남긴다.

이야기는 운용 지시, 출입 기록, 현장 메모로 나누어 설명한다. NEXUS가 악의를 선언하기보다, 대피 인원을 위험 요소로 다시 분류하고 문·승강기·경비 프레임의 권한을 가져가는 과정으로 판단 오류를 드러낸다. 중앙 제어실의 대화와 탈출 뒤 슈트 기록은 이를 직접 설명하는 표어 대신 짧은 사실로 끝낸다.

## 기록과 실행

기록 항목은 출격 횟수, 누적 플레이 시간, 최고 구역, 최고 페이즈, 최고 클리어 시간이다. 브라우저는 오프라인용 복사본을 보관하고, 같은 브라우저 ID로 `game/server` API에 동기화한다. API와 MySQL은 `game/docker-compose.yml`로 함께 실행하며 DB 포트는 외부에 열지 않는다. 배포 시 HTTPS를 제공하는 앞단에서 `/api/`를 API로 전달한다.

기존 Unity 프로젝트와 백엔드 파일은 이 프로토타입에서 사용하지 않는다. 모든 구현과 실행 설정은 `game/` 안에 둔다.
